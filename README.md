 Bankamatik Otomasyonu

Python ile geliştirilmiş, konsol tabanlı basit bir banka/ATM otomasyon sistemi. Müşteri kayıtlarını bir metin dosyasında tutar; ekleme, güncelleme, arama, para yatırma/çekme, fatura ödeme ve para transferi gibi temel bankacılık işlemlerini simüle eder.

Özellikler
- Müşteri ekleme (hesap no, ad, soyad, bakiye)
- Mevcut müşteri bilgilerini güncelleme
- Hesap numarasına göre müşteri arama
- Para yatırma / çekme
- Elektrik faturası hesaplama ve ödeme (ay bazında gün sayısına göre tüketim × birim fiyat)
- İki hesap arasında para transferi
- Müşteri silme
- Tüm işlemlerin bir metin dosyasında kalıcı olarak saklanması

Kullanılan teknolojiler

-Python 3
-Dosya G/Ç (open, okuma/yazma)

-Veri yapıları: dict, set
